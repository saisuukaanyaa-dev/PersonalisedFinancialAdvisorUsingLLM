# NIFTY 50 Historical Example

**Category:** membership_methodology

## Instruction
Does appearing in the yearly NIFTY 50 list mean there were more than 50 constituents at the same time?

## Context
{"important_distinction": "A calendar year can contain more than 50 distinct companies because constituents change during the year."}

## Response
No. The NIFTY 50 maintains 50 constituents at a given reconstitution period. More than 50 distinct companies can appear in a calendar year because some companies leave and others enter during that year.
