# NIFTY 50 Historical Example

**Category:** dataset_methodology

## Instruction
What does price_data_status=unavailable mean in this dataset?

## Context
{"price_data_status": "unavailable", "rule": "Do not infer, substitute, or treat missing data as zero."}

## Response
It means the required historical price series was not available from the selected market-data source for that company and period. The dataset does not assign a zero return or substitute another company, bank, ETF, or successor security.
